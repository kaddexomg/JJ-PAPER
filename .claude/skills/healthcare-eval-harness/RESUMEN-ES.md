# healthcare-eval-harness

Harness de evaluación de seguridad de paciente para deploys de apps de salud. Suites de test automáticas para precisión de CDSS, exposición de PHI, e integridad de workflow clínico. Bloquea deploys si fallan los checks de seguridad.

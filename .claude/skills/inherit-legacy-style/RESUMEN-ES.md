# inherit-legacy-style

Skill de herencia de estilo para proyectos legacy. Usar al integrar un agente de IA en un proyecto escrito a mano, para evitar que el modelo imponga sus idioms mainstream por defecto. Agnóstico de lenguaje/framework, alinea solo meta-arquitectura, no sintaxis.

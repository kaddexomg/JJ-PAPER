# recsys-pipeline-architect

Diseña pipelines componibles de recomendación/ranking/feed usando el framework de seis etapas Source→Hydrator→Filter→Scorer→Selector→SideEffect. Para cualquier sistema que elige "el top K de items para un (usuario, contexto)": feeds, CMS, rerankers de RAG, o ranking de ads.

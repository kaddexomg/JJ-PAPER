📥 Importar Productos en Masa — CSV

Cada fila = una variante (producto + marca + presentación). Encabezados:

name, brand, variant, category_slug, sku, description, price_usd, cost_usd, margin_pct, unit_abbr, emoji, tag, featured, active, stock, min_qty
  • Solo name y price_usd son obligatorios. Repite el name para agregar varias marcas, y variant para la variedad dentro de la marca (color, tamaño, contenido…).
  • Marcas que no existan se crean automáticamente.
  • Si el producto+marca+presentación ya existe, se actualiza (precio, costo, stock…) — re-importa el CSV para actualizar stock en masa.

Selecciona un archivo CSV para previsualizar antes de importar.

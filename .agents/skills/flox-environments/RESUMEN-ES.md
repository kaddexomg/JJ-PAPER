# flox-environments

Crea entornos de desarrollo reproducibles y cross-platform (macOS/Linux) con Flox, un gestor de entornos declarativo basado en Nix. Usar para toolchains de proyecto, dependencias a nivel sistema, versiones fijas para el equipo, servicios locales, o resolver "funciona en mi máquina".
